> **새 채팅에서 처음 볼 문서: [`NEXT_CHAT.md`](NEXT_CHAT.md).** 현재 기준으로 실제 구현된 것과 아직 해야 할 일을 빠르게 확인한 다음, [`BACKLOG.md`](BACKLOG.md)에서 작업을 이어간다.

| 파일 | 목적 |

## 업데이트 규칙

1. 기능 변경 시 같은 PR에서 관련 문서를 함께 수정한다.
2. 검증되지 않은 사실은 **미검증**이라고 표시한다. 테스트 결과와 승률은 실제 기록으로만 갱신한다.
3. UI는 사용자 눈에 필요한 것만 노출하며 연구 도구는 AI 비교에 분리한다.
4. AI 성능 향상은 **동일 시드 + 좌석 교환 + 충분한 대국 수**를 기준으로 판단한다.
5. 온라인 멀티플레이와 로컬 2인전을 혼동하지 않는다.
6. 추후 스펙이 바뀌면 `DECISIONS.md`에 왜 바꿨는지 기록한다.
