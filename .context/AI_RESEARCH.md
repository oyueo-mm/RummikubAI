# AI 연구 노트

## 기준선

- `Random`: 합법 타일 조합 중 임의 선택, 비교용.
- `Greedy`: 손패 조합 DP로 당장 가능한 타일 최대화, 이후 기존 조합 한 장씩 확장.
- `Strategic v1.1` (`strategic`): Greedy 행동을 보존하면서, 테이블 일부 조합 1~2개와 관련 손패를 골라 **국소 Exact Cover 재배열** 탐색. 더 많은 타일을 내려놓을 때만 적용.

## 전략 AI v1.1 범위

- 기존 보드+손패 총합 15개 이하면 전체 작은 보드의 `candidateMelds` 정확 제약 탐색을 사용할 수 있다.
- **큰 보드**에서는 테이블의 관련 조합 1~2개(총합 10개 이하)를 뽑고 연관 손패를 더해 **총합 15개 이하인 최대 16개 국소 문제**를 Exact Cover로 해결한 뒤, 남은 손패에 Greedy 후처리를 적용한다. 기존 나머지 보드 조합은 불변으로 보존한다.
- 더 많은 타일을 낼 수 없거나 제한 탐색이 실패하면 Greedy로 폴백. **전체 게임에 대한 최적 행동이라는 주장이 아님.**
- 더 많은 타일을 즉시 배치할 수 있어도 최종 승률이 높아졌다는 근거는 아님. 장기 손패 구조, 조커 관리, 상대 턴 대응 미반영.

## 2026-11-23 초기 재현 실험

- **v1 (작은 전체 보드만)**: 시드 1800부터 20쌍, 40판 → Strategic 18승 / Greedy 18승 / 무승부 4. 명확한 개선 관측 안 됨.
- **v1.1 (큰 보드의 국소 Exact Cover 추가)**: 시드 1800부터 20쌍, 40판 → Strategic 40승 / Greedy 0승 / 무승부 0.
- **독립 검증**: 시드 6000부터 60쌍, 120판 → Strategic **116승** / Greedy **4승** / 무승부 0. 경험적 승률 **96.7%**.
- 방법: 두 AI 동등한 초기 시드에서 **시작 자리 교환**, 양쪽 모두 같은 규칙과 일반적인 주사위 없는 타일 분배, 180턴 제한. 전 게임 `capped=0`.
- 검증: 자동 테스트 57개 통과, 8개 독립 게임에서 **106 타일 보존·전체 테이블 조합 유효·첫 등록 최소 30점** 점검.
- 실행: `node bench/compare.mjs 40 1800`, `node bench/compare.mjs 120 6000`; CI 로그 및 코드/시드로 재현 가능.
- 해석: **현재의 약한 Greedy 기준선보다 큰 성능 향상이 관측됨**. 상대가 강한 AI일 경우, 사람 상대 실력, 일반화, 불완전정보 의사결정에서는 우월성이 입증된 것은 아니다.

## 연구 질문

1. 제한적 정확 재배열이 일반적인 Greedy보다 실전 승률을 개선하는가?
2. 손패 타일 수 최대화와 잔여 랙 유연성·패널티 최소화는 얼마나 다른가?
3. 숨겨진 상대 패를 샘플링한 ISMCTS가 충분한 시간 예산에서 유의미한 향상을 보이는가?
4. 계산시간을 고정하면 후보 생성·재배열·탐색 각각의 성능 기여가 어느 정도인가?

## 재현 가능한 평가 계획

- 두 AI를 동일 시드에서 선후공 교대 (paired-seat), 독립 시드, 게임 종결/턴 제한 분리 집계.
- 승/패/무, 실제 배치 손패 수, 벽시계 계산시간, 불법 이동 수(0이어야 함), 전체 승률 신뢰구간.
- 짧은 UI 내 20판은 연기 검증이 아닌 **빠른 회귀용**이다. 모델 우월성 주장은 최소 수백~수천 판 이상과 신뢰구간 및 재현 로그를 확인한 뒤 결정.
- 실제 결과가 없으므로 **Strategic v1이 더 강하다고 단정할 수 없음.**
