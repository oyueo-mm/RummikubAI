## 현재 코드 범위

- 106개 타일(조커 2개), 2인 루미큐브 규칙, 첫 등록 30점, 손패/기존 테이블 보존 검증
- 홈 → AI 대전 또는 같은 기기 사람 2인 대전 (온라인 접속/매칭 아님)
- 로컬 대전 차례 전환 오버레이, 상대 손패 UI 비노출
- 타일 드래그, 색상·숫자 정렬, 100단계 Undo/Redo, 임시 조합, 턴 완료 검증
- 길게 누른 타일부터 **뒤쪽의 물리적으로 인접한 유효한 조합**을 함께 선택
- 조합에 추가한 타일은 완성된 합법 조합일 때 자동 정렬
- 사운드와 음소거; 장식적 빛 효과가 없는 단색 UI
- Random / Greedy / 탐색 AI v1 (제한된 테이블 정확 재배열)
- 20판 자동 비교 도구 (탐색 vs Greedy, 시드·자리 교환)

## 알려진 한계 및 다음 작업

- 실제 모바일·데스크톱의 시각적/드래그 검증 필요
- 온라인 멀티플레이, 계정·매칭·실시간 동기화 없음
- 탐색 AI의 정확 재배열은 손패+테이블 합계 **최대 15개**일 때만 동작. 더 큰 보드에선 Greedy 기반
- 정보집합 MCTS·상대 손패 추론·정책 학습 미구현
- 일부 조커 회수/변형 규칙과 3~4인 대전 미구현
- 장시간 독립 시드 벤치마크와 신뢰구간 분석 필요
