# UI/UX 설계 기준

## 구조

- 홈: **AI와 플레이 / 사람과 플레이(같은 기기, 2인)** 두 선택지. 과도한 소개 문구 없음.
- 플레이: 상단 최소 내비게이션, 왼쪽 참가자, 중앙 넓은 테이블, 하단 2줄 랙, 오른쪽 뽑기/취소/완료.
- AI 비교: 연구 실험과 모델 설명. 플레이 화면에 연구 수치 노출하지 않음.
- 광고·가짜 3D·광택·그라데이션·글로우·강한 그림자 없음. 흰 타일과 단색 파란 테이블, 선명한 숫자만.
- 테이블 조합은 인접하게 촘촘히 정렬하며 작은 화면에서는 랙과 조작 버튼을 압축.

## 타일 조작

- 짧게 클릭: 단일 선택. 짧게 드래그: 단일 또는 이미 선택한 묶음 이동.
- **길게 누르기(약 330ms)**: 현재 타일에서 시작해 같은 랙 줄(또는 같은 테이블 조합)의 **바로 오른쪽 연속 타일**만 자동 선택. 조합을 깨는 타일에서 즉시 중단. 떨어져 있는 타일은 자동으로 찾지 않는다.
- 같은 색 연속 숫자 및 같은 숫자 다른 색의 그룹을 인식. 조커도 연속 조합에 들어갈 수 있다.
- 현재 손패에 유효하게 없는 임의의 조합을 자동 생성하지 않는다.
- 기존 조합에 타일을 놓으면 **뒤에 추가**, 전체 조합이 법적으로 유효해지는 순서가 있다면 자동 정렬한다.
- 미완성 임시 배치를 허용하지만 턴 완료는 전체 테이블·첫 등록·타일 보존 검증 후 확정.
- 되돌리기/다시 실행, 턴 전체 초기화, 소리 켜기/끄기.

## 사람 대 사람

- 동일 브라우저에서 번갈아 진행한다. 차례 전환 시 손패를 가리는 준비 화면을 표시.
- 이 기능은 온라인 멀티플레이를 뜻하지 않는다. 친구 초대/원격 플레이는 후속 과제.

## 평가해야 할 항목

- 첫 조합 생성 시간, 드롭 실패율, 잘못된 조합 경고, 되돌리기 비율, 모바일 탭/드래그 성공률.
- 데스크톱 최소 일반 해상도·모바일 가로세로·키보드 단축키.
