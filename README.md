# RummikubAI

**루미큐브 AI 게임 및 연구 플랫폼** — [플레이 사이트](https://oyueo-mm.github.io/RummikubAI/)

정확한 타일 조합, 불완전정보 전략 탐색, 자기대국 학습을 단계적으로 연구하는 프로젝트입니다.

## v0.1 구현 상태

- 2인 사람 대 AI 게임, 106개 타일, 시드 기반 셔플, 최초 14개 배분
- 같은 숫자/서로 다른 색 그룹, 같은 색/연속 숫자 런, 조커 조합 판정
- 최초 등록 30점, 테이블 재배열, 전체 타일 보존·중복·유효 조합 검증
- 타일 선택 → 새 조합, 앞뒤 추가, 변경 취소, 뽑기, 손패 기반 힌트
- Greedy AI: 손패에서 최대 타일 개수 조합 탐색 (18개 이하는 정확한 DP, 19개 이상은 근사)
- Random AI: 비교 기준선 (가능한 손패 조합 무작위 선택)
- 이미 등록한 AI는 기존 테이블 조합의 단순 확장 가능
- 동일 시드, 두 자리 교체 조건으로 Greedy vs Random 20판 비교
- Node 내장 테스트 및 GitHub Actions CI

## 한계 — 반드시 구분

**현재는 완전한 루미큐브 최강 AI가 아닙니다.**

- 기존 테이블을 **전체 재배열하는 자동 솔버는 미구현**입니다. 사람이 타일을 옮겨 배치할 수는 있습니다.
- 첫 등록 전 30점 제약은 적용했지만 조커 회수의 판본별 상세 조건은 완전 구현하지 않았습니다.
- 2인전만 지원합니다. 3~4인, 멀티플레이, 정식 토너먼트는 미구현입니다.
- AI 자동 비교는 초기 확인용으로, SOTA나 통계적으로 확증된 실험이 아닙니다.
- MCTS / ISMCTS / 강화학습은 구현되지 않았습니다.
- 타일 조작은 클릭 기반입니다. 드래그 앤 드롭은 후속 개선 대상입니다.

## 로컬 실행

브라우저가 JS 모듈을 불러올 수 있도록 간단한 HTTP 서버를 실행합니다. 별도 의존성 설치는 필요하지 않습니다.

~~~bash
python -m http.server 8000
~~~

http://localhost:8000 에 접속합니다.

Node.js 20 이상에서 테스트:

~~~bash
npm test
~~~

## GitHub Pages

워크플로 파일은 .github/workflows/pages.yml 에 있습니다. Pages가 아직 활성화되어 있지 않으면 GitHub 저장소 Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택해야 배포가 성공합니다.

## 연구 로드맵

1. 조커 회수 제약 및 전체 규칙 테스트 완성
2. MILP/CP-SAT/DP 기반 완전한 테이블 재배열 솔버
3. 정확한 솔버를 기준선으로 하는 휴리스틱과 ISMCTS
4. 짝지은 시드·자리 교환·동일 연산 예산·신뢰구간 실험
5. 정책 증류 및 자기대국 강화학습

## 디렉터리

- engine.js : 규칙 / Greedy / Random / 자동 대국
- app.js : 플레이 및 벤치마크 UI
- styles.css : 반응형 무광 UI
- tests/engine.test.js : 엔진 회귀 테스트
- .github/workflows/ci.yml : 테스트
- .github/workflows/pages.yml : 정적 사이트 배포
