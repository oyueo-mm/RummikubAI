## v0.7 — AI 대국 관전 · 6개 모델 · 공정 비교

- **AI 대국 관전**: 홈의 세 번째 선택지 또는 상단 탭에서 두 모델을 골라 대국 관전. 재생/일시정지, 한 턴씩 진행, 0.5–8배속, 동일 시드 다시 보기, 새로운 시드, 양쪽 손패 보기.
- **모델 6종**: Random, Greedy, Joker Guard(조커 사용 절제), Exact Small(최대 15개 타일에서 전체 보드 재배열), Strategic v1.1(국소 정확 탐색 16문제), Strategic+ v1(국소 탐색 48문제).
- **AI 비교**: 어떤 두 모델이든 동일 초기 시드에서 자리를 교환하며 20·40·100판 비교. 시드를 지정하고 결과를 재현할 수 있음.
- **명령줄 재현**: `node bench/matchup.mjs 40 9000 strategic-plus strategic`. 인자는 [짝수 대국 수, 시작 시드, 모델 A, 모델 B]. `npm run benchmark`로 기본 매치업 실행.
- **강함에 대한 주의**: 탐색 예산 확대는 계산시간을 늘리며 반드시 승률을 개선하지 않음. 현재의 6개 모델은 SOTA 도전용 초기 기준선과 연구 모델이지, 최강 성능을 공인받은 모델이 아님.
- **관전과 학습은 구분**: 화면에 나타나는 자동 대국은 모델을 학습시키지 않음. ISMCTS, 자기대국 RL, 정책 증류는 후속 연구 과제.
- **초기 재현 결과:** Strategic+ vs Strategic v1.1 **200판 127승·73패(63.5%)**. 단, 계산 예산이 다른 비교이므로 SOTA 또는 시간 효율의 우위는 미검증.
- **수동 장시간 연구:** GitHub Actions의 **AI Research Benchmark**에서 모델·게임 수·시드를 선택하고 JSON 결과 내려받기.

## v0.6 — 홈 · 조합 자동 정렬 · 로컬 2인전 · 탐색 AI

- **홈:** `AI와 플레이`, `사람과 플레이` 중 선택. 사람 대전은 **같은 기기에서 번갈아 진행하는 2인전**이며 온라인 매칭은 지원하지 않음.
- **롱프레스:** 약 330ms 누르면 해당 타일부터 **같은 줄 바로 오른쪽에 연속된 규칙 호환 타일**을 함께 집음. 손패 전체를 검색하거나 손가락이 스친 모든 타일을 모으지 않음.
- **드롭 정렬:** 유효하게 완성되는 조합이면 추가 타일을 기존 조합에 붙인 뒤 자동 숫자순·색상순 정렬. 미완성 임시 배치는 그대로 유지.
- **플레이 화면:** 고정 대형 대시보드 대신 적정 너비의 게임판, 촘촘한 조합, 하단 랙을 중심으로 간결하게 배치.
- **AI:** `Strategic v1`은 관련 보드 조합·손패 합계 최대 15개를 국소 정확 재배열로 탐색하고, Greedy보다 더 많은 타일을 낼 때만 채택. **기준선 Greedy와 비교한 40판 전승 및 독립 120판 116승(96.7%)**이 관측됨. 다른 강한 AI 대비 우위와 SOTA는 미검증.
- **AI 비교:** Strategic vs Greedy 20판, 같은 시드에서 시작 위치를 교환.
- **연구 재현:** `npm run benchmark` 또는 `node bench/compare.mjs 100 1800` (게임 수는 짝수).
- **맥락 보존:** `.context/` 문서와 `AGENTS.md`에서 현황·UI·AI·결정 이력을 지속 관리.

## v0.5 — 단색 UI · 수동 꾹 누르기 · 효과음

- 단색 파란 게임판·흰 타일·단색 랙. 그라데이션·글로우·과장된 그림자 제거
- 상시 노출되던 첫 등록/내 차례/테이블 개수/타일 개수/꾹 누르기 설명 제거
- 왼쪽 두 플레이어는 **현재 차례인 프로필 테두리**로만 구분
- 오른쪽 **뽑기 · 되돌리기 · 완료** 버튼 유지, 하단 Undo/Redo/힌트·정렬 기능 유지
- 필요할 때만 오류 알림: 첫 등록 30점 미달, 조합 오류, 잘못된 이동 등
- Web Audio API 기반 작고 짧은 효과음. 음표 버튼으로 음소거, 설정 저장, 파일·서버 불필요

**꾹 누르기(약 310ms) 동작**

1. 타일 하나를 누른 상태로 유지하면 **그 타일 하나만** 묶음에 들어갑니다. 가능한 조합을 자동으로 추천하거나 추가하지 않습니다.
2. 누르고 있는 포인터를 다른 타일 위로 옮기면, **실제로 지나간 타일만 하나씩 추가**됩니다.
3. 다른 타일을 건너뛰거나 원래 타일로 돌아와도 자동으로 조합을 완성하지 않습니다. 이미 묶은 타일을 벗어났다가 다시 지나가면 묶음에서 제거할 수 있습니다(첫 타일은 유지).
4. 게임판 위에 손을 놓으면 묶인 타일들을 동시에 이동합니다. 랙에서 손을 떼면 선택을 유지합니다.
5. 짧게 클릭해 여러 타일을 선택하는 기존 조작과 Undo/Redo는 계속 지원합니다.
6. 손패와 테이블의 타일은 각각 동일한 출발 영역에서만 묶습니다. 첫 등록 이전에는 기존 테이블 타일 이동을 제한합니다.

타일 이동 시점에는 임시 미완성 조합도 만들 수 있지만, **턴 완료 시에는 전체 테이블과 첫 등록 30점 규칙을 검증**합니다.

## v0.3 — 테이블 중심 시각 디자인

초기 0.2 버전의 빈 회색 패널과 화면 전체를 채우는 손패 배경을 재설계했습니다.

- **게임판:** 채도가 낮은 블루그린 테이블, 첫 턴용 중앙 드롭 가이드, 타일 배치 시 불필요한 패널 최소화
- **타일:** 크기 확대, 아이보리 타일과 숫자 대비 강화, 보드의 그룹 표현 정돈
- **손패:** 타일에 맞는 크기의 독립 랙으로 변경하여 주변 여백 축소
- **AI 비교:** Greedy와 Random의 승패 스코어, 비율 바, 판별 결과 점으로 보여주는 대결 화면
- **게임 동작:** 조합 이동·되돌리기·정렬과 실험 방식은 기존 버전의 기능을 유지

시각 디자인 변경이며 더 강한 AI가 추가된 것은 아닙니다.

## v0.2 — 제이콥의 법칙 기반 UI 개편

기존 루미큐브 게임의 공간 배치를 따르는 **상대 정보(상단) → 넓은 테이블(중앙) → 2줄 손패 랙(하단)** 구조로 재설계했습니다. 연구용 정보는 별도 **AI 비교** 탭으로 분리했습니다.

- 마우스·터치 **타일 드래그 앤 드롭**; 타일 여러 개를 선택해 묶음 이동
- 테이블 빈 곳으로 놓으면 새 조합 생성, 기존 조합에 놓으면 삽입
- 임시로 미완성 조합을 만들 수 있으며, **턴 완료 시 전체 규칙 검증**
- **100단계 Undo/Redo** (Ctrl/Cmd+Z, Ctrl+Y 또는 Cmd+Shift+Z), 턴 전체 되돌리기
- **색상순 / 숫자순** 손패 정렬
- 데스크톱 우클릭·드래그 패닝, 터치 배경 드래그 패닝, 두 손가락 확대, Ctrl+휠 확대, 확대 버튼
- AI 힌트에서 추천 타일 하이라이트, 타일 드롭 피드백과 축소 애니메이션
- 새 게임 설정에서 Greedy·Random AI 선택, 화면에서 불필요한 AI 내부 정보 제거
- 반응형 UI, 키보드 포커스 표시, reduced-motion 지원

### 기본 조작

| 행동 | 방법 |
| --- | --- |
| 타일 하나 선택 | 클릭·탭 |
| 여러 타일 선택 | 타일을 차례로 클릭·탭 |
| 타일 조합 만들기 | 선택한 타일을 테이블의 빈 곳에 드래그하거나 **선택 조합** |
| 조합 사이 이동 | 타일을 다른 조합으로 드래그 |
| 손패로 되돌리기 | 원래 내 손패였던 타일을 랙으로 드래그하거나 **손패로** |
| 배치 되돌리기 | Undo / Redo 아이콘, Ctrl+Z / Ctrl+Y |
| 턴 전체 초기화 | 원형 화살표 버튼 |
| 타일을 뽑기 | 배치를 변경하지 않은 상태에서 **타일 뽑기** |
| 턴 제출 | 모든 조합을 유효하게 만든 뒤 **턴 완료** |

## AI 현재 구현 범위

- 총 106개 타일(조커 2개), 2인 대국
- 첫 등록 30점, 그룹·런 유효성 검증 및 전체 타일 보존 검사
- Greedy: 손패에서 가능한 조합을 최적화 (손패 18개 이하 DP, 초과 시 근사)
- Random: 합법 조합 무작위 선택
- 기존 테이블의 **단순 확장**, 손패 기반 힌트
- 같은 초기 시드와 자리 교환을 이용한 Greedy / Random 20판 비교

**한계:** 완전한 테이블 재배열 솔버, ISMCTS, 강화학습, 3~4인 대국, 일부 판본별 조커 회수 제약은 미구현입니다. 게임 UI의 자유로운 재배열과 AI 솔버의 탐색 능력은 구분해야 합니다.

## 개발 및 테스트

추가 프론트엔드 패키지나 API 서버 없이 웹에서 실행됩니다.

~~~bash
python -m http.server 8000
npm test
~~~

Python 서버 실행 시 http://localhost:8000 에서 플레이할 수 있습니다. Node.js 20 이상을 사용하세요.

구조: `app.js` (인터페이스), `draft.js` (불변 이동·Undo/Redo), `styles.css` (UI), `engine.js` (규칙·AI), `tests/` (회귀 테스트).
